Database routing

System 1 · Jev

"Does this database contain the data?"

One boolean per database, all in a single call. Keeps every database ≥ databaseThreshold.

No database selected The agent answers "no database can answer this" and the LLM is never called. This is what keeps hallucinations at zero.
2

Table routing

System 1 · Jev

"Is this table needed to write the query?"

One boolean per table of the chosen databases. Keeps the top maxPreloadedTables ≥ tableThreshold.

Why booleans Overlapping databases can all score high. A single choice would split the probability between them.
3

Column preload

PostgreSQL

Columns, types and comments of the selected tables are read from Postgres and written into the executor prompt.

Effect The LLM writes the SQL on the first try instead of guessing column names.

Execution

System 2 · LLM

Tools listColumns and runQuery, restricted to the routed databases. Every query runs READ ONLY and is rolled back.

Result ~6x fewer input tokens than an agent that reads every schema.
